## English learning — where it fits (v3)

Added **two 20-minute slots (40 min/day total)** — both inside time that was already "dead" or low-focus, so nothing else got compressed:
- **5:15–5:35** — vocab/grammar app (Duolingo, Anki, whatever) right after Fajr when the mind is fresh but not yet ready for deep coding focus
- **9:30–9:50** — reading (a book, article, or even subtitles-on show) as part of the no-screen wind-down — reading counts as "no screen" if it's a physical book, otherwise swap this slot for audio instead

**Bonus (free, no time cost):** switch breakfast (8:00–8:30) or dinner background media to English audio/podcast — passive listening exposure adds up without taking a dedicated slot.

## What changed from v1

- **Learning: 1.25h → 3.5h/day** (split into two blocks — 8:30–10:30 and 2:00–3:30 — so it doesn't kill focus in one long sitting)
- **Deep work: 6h → 4.25h/day** (2h + 1.5h + 45m) — still enough for daily progress if you stay on ONE project per week, but the margin for slippage is thinner now
- **Content: still ~2.25h/day**, unchanged, split across 3 short blocks

## Heads up

3.5h of daily backend learning is a serious, real commitment — good if you're trying to move fast on the course. But it does eat almost 2 hours out of what was deep project work. Two ways to handle it if project deadlines get tight:

1. **Trade content time**, not learning time, first — content can survive a lighter week; unfinished client/product work can't.
2. Once you finish the current course module/milestone, drop learning back to ~1.5h/day maintenance mode and shift that time back to Deep Work.
